② 省钱技巧

  • 分档用模型：批量速读/翻译用便宜模型（glm-4-flash、qwen-turbo），只有「研究新思路」「综述大纲」这类需要深度思考的才上好模型。
  • 控制上下文：本工具已限制输入长度；摘要优先用「AI 速读」而不是把整篇长文贴进去。
  • 设用量上限：在各服务商后台设置月度消费上限，防止误刷。
  • 薅免费额度：智谱、硅基流动、OpenRouter 三家同时注册，额度可叠加使用，基本够一学期。
  • 别用最贵模型跑批量：gpt-4o 级别做日常摘要性价比极低。

④ 隐私与安全

  • Key 只存在你自己的浏览器本地（localStorage），本工具没有任何后端，不会上传到任何服务器。
  • 发送给 AI 的内容是论文标题与摘要；若论文涉密，请用 Ollama 本地模型。
  • 共用电脑请勿保存 Key，或用完后点「清空」。建议定期在服务商后台轮换 Key。
  • 换设备时，可用「设置 → 数据备份与导出」导出后再导入。

⑤ 本地部署（Ollama，完全免费）

  1. 安装 ollama.com，终端执行 ollama run qwen2.5:7b（约 4GB，或更小的 qwen2.5:3b）。
  2. Base URL 填 http://localhost:11434/v1，模型填 qwen2.5:7b，Key 随便填一个非空值即可。
  3. 若浏览器报 CORS，先退出 Ollama，设环境变量 OLLAMA_ORIGINS=* 再启动。

⚠️ 各家免费政策会调整，具体以服务商官网为准；模型名也可能更新，请以官方文档的模型列表为准。
